# SHAP Explainability Results

This folder contains SHAP explainability results for the final 75-feature XGBoost ICU-transfer prediction model.

## Included Results

- **Feature Importance:** Ranks the most influential predictors.
- **SHAP Beeswarm:** Shows how individual feature values influence model predictions.
- **Laboratory Group Importance:** Examines the combined contributions of laboratory-derived features.
- **Feature Ranking:** Provides numerical SHAP importance values.

## Key Objective

To understand which laboratory measurements and clinical features contribute most to predicted ICU-transfer risk.

SHAP explains model predictions but does not establish clinical causation.

## Limitations

The analysis is retrospective and exploratory. The model has not been externally validated for clinical use.
