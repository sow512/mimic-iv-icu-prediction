# SMOTE Analysis Results

This folder contains baseline versus SMOTE/SMOTENC experiments for ICU-transfer prediction using different feature configurations.

The results compare AUROC, AUPRC, recall, precision, F1-score and false-positive counts to evaluate the effect of oversampling on rare ICU-transfer events.

SMOTE improved recall in some experiments but generally reduced precision and AUPRC, increasing the false-alert burden.
